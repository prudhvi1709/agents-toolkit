# Replay Theater

Review the last completed turn's successful foreground `Edit` and `Write`
changes one diff at a time. Type `/replay` or press the hint's Review button.
Use Prev/Next, numbered steps, or focused-pane `p`/`n`; Close, `x`, or Escape
closes the pane. Typing `r` in the prompt is not intercepted.

This is an original implementation of the behavior described in Anthropic's
[mods guide](https://claude.dev/blog/getting-started-with-claude-code-mods/),
using the API declarations generated by the installed Claude Code version.
The pane uses native diff highlighting and placement on terminal and Desktop.
It preserves other mods' status bands and yields to surveys.

Snapshots before and after a successful tool result reflect actual file
changes. Failed, denied, and unchanged calls add no steps. A turn with no
captured changes clears the previous replay. State survives hot reloads for
the current session; no transcript export or persistent file store is created.

## Limits

- Only foreground `Edit`/`Write` calls are captured, not Bash, notebook, MCP,
  subagent, or external-editor changes. Concurrent external changes to the same
  file can be included in the observed before/after snapshots.
- Each turn retains up to 24 steps; additional successful calls are counted
  as omitted. Snapshots are limited to regular files of at most 64 KiB.
- Each diff is one replacement hunk, including unchanged lines between distant
  changes. Diffs above 9,000 characters show a notice directing you to `/diff`.
- Snapshot failures show an explicit gap. Replay never prevents an edit or
  changes a tool result. It does not implement undo.

## Install and verify

Copy this folder to `~/.claude/mods/replay-theater` and append its absolute path
to `env.CLAUDE_CODE_PLUGIN_DIRS` in local Claude settings. Restart Claude Code.
Keep settings and generated `.claude-plugin/types/` declarations out of Git.

```bash
claude plugin validate mods/replay-theater
claude plugin test mods/replay-theater
```

The tests exercise real hook handlers and native UI trees. Confirm native
painting in a live session after installation.
