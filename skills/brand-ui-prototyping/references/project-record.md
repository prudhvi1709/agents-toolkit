# Project record template

Copy this into the project's own handoff location (not into this shared
skill, and not into a public repository if any entry is client-private).
Fill it in as the work happens; do not reconstruct it at the end.

| --- | --- | --- | --- |
| e.g. primary logo SVG | approved brand asset | `path/or/sources.json entry` | hero, nav |

implementation**, **inspiration**, **generated concept**. Never promote an
inspiration or generated row to approved without an explicit decision below.
