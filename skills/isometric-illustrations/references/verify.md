# Verify the illustration

Build in a temporary copy so global skill source remains unchanged. Node uses
only built-in modules for the bundled example:

```sh
node examples/dial-indicator/build.mjs
node examples/dial-indicator/build.mjs --light
```

For a new figure with pipes, curved parts or an exploded view, record every
drawn shape with the matching kit/audit.mjs helpers. Connect `auditOrExit` to
the build's --audit flag and check its exit code and report. A successful report
validates the recorded geometry and sampled states, not the subject's physics.
Do not substitute stand-in shapes or silence a failure with painter's key bias.

Use the installed playwright-verification skill for console, network,
accessibility and responsive reports. Use isolated browser automation to check
pointer, keyboard, touch, reduced motion and WebGL-disabled states as applicable.
The upstream capture, drive and line-end browser scripts are not bundled.

Inspect desktop and phone renderings and close-ups of uncertain joints. Check
occlusion, pipe endpoints, text clipping, contrast and visible focus. Test the
requested theme; check both only if both ship. Confirm the SVG still communicates
the essential mechanism without WebGL, and provide a caption/static alternative
if JavaScript is disabled. Under reduced motion, idle tours stay off and input
changes the state without spring bounce.

For standalone output, check browser console and computed styles under the
generated CSP. The wrapper hashes exact generated scripts, style blocks and
style attributes. Editing the HTML after building invalidates those hashes.
The wrapper supports the kit's generated template, not arbitrary external HTML.
For site integration use external modules/styles and the project's policy.

Check explanatory truth separately: trace every readout to the same model as
the geometry, compare counts and units with sources, and describe metaphor
limitations. Report skipped checks and uncertain behavior rather than claiming
full verification.
